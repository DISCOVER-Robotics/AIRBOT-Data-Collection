# Camera Calibration

该文档介绍如何进行相机的内参和外参标定。

## Installation

本标定流程需要依赖[caliscope](https://github.com/mprib/caliscope?tab=readme-ov-file)，需要先安装该库：

```bash
pip install caliscope
```

## Usage

### 完成数据采集配置

进行相机标定前，需要先完成数据采集配置，至少要包括相机的配置。如果配置文件中包含其他的设备（例如机械臂）且不希望在标定时启动，可执行如下命令

### 准备标定板

相机内外参标定均需要使用标定板，这里使用了二维码（charuco）标定板，同时可支持内参和外参标定，省去了额外打印标定板的麻烦。默认标定板文件位于`charuco.png`，直接打印使用即可，该标定板对应的参数信息位于`config.toml`。如果希望使用其他标定板，请参考[caliscope文档](https://mprib.github.io/caliscope/calibration_board/)。

注意：

- 使用真正平整的标定板对于获得高质量的相机内参标定至关重要。标定算法的核心假设是：所有特征点都位于同一个平面上。如果使用胶带随意粘贴的纸张或已发生翘曲的纸板作为标定板，将严重损害标定结果的准确性。
- 内参与外参标定可使用不同的标定板（需要在运行每次标定前相应地调整标定板的定义参数）。内参标定时可选用一块更加平整、对齐精度更高的标定板；而在进行外参标定时，则可使用由多张纸拼接而成的更大尺寸标定板，以覆盖更大的捕捉空间，便于多相机系统的外参标定。
- 对于一组固定的相机，内参标定只需执行一次，之后可在使用相同相机的后续项目中直接复用该内参配置。

### 视频录制

准备好标定板后就可以对其录制视频了。

#### 内参

```bash
airdc +demonstrator.instance.components.ignore_roles="[l,f]" samplers=video_each dataset.directory=scripts/calibration/camera/calibration/intrinsic
```

上述命令会同时启动多个相机，但会依次采集每个相机的视频数据，采集顺序与配置文件中相机的顺序一致。
因此，首先查看配置文件中第一个相机的名称，然后将标定板放置在该相机前方进行录制，保存后，下一次采集会自动按顺序切换到下一个相机，依次类推，完成所有相机的视频采集。完成后，将会在`dataset.directory`指定的目录下找到每个相机的视频文件。

有如下录制建议：

- 自由移动相机或标定板
  - 在直接监看相机画面时，更容易采集到高质量的数据。
  - 相机的位置无需与外参标定时完全一致（标定板也不必使用同一个）。

- 尽量减少运动模糊：
  - 动作要缓慢、平稳。
  - 使用较高的快门速度以减少运动模糊。
  - 确保充足的照明，以便在不使视频曝光不足的前提下使用更快的快门速度。

- 提供透视缩短（Foreshortening）效果：
  - 将标定板以不同角度朝向相机摆放。这种透视缩短对校准过程至关重要，因为它能提供更多关于相机镜头特性的信息。
  - 拍摄时应包含多种姿态：有些画面中标定板朝向相机倾斜，有些远离相机，还有一些呈侧向角度。

- 覆盖整个视场范围：
  - 在整个相机视场范围内移动标定板，以确保校准能涵盖图像传感器全域的镜头畸变及其他特性。

- 使用高质量的标定板：
  - 标定板应打印在平整、坚硬的材料上，防止翘曲变形。

- 改变拍摄距离：
  - 在不同距离处拍摄标定板，有助于理解相机在不同景深下的聚焦特性。

- 保持对焦一致：
  - 如条件允许，请使用手动对焦，以在整个录制过程中保持焦点稳定。
  - 自动对焦可能会在不同镜头间产生不一致，影响标定效果。

- 充足且合适的照明：
  - 确保场景光线充足，避免视频中出现噪点和颗粒，这些会干扰标定过程。
  - 避免使用强烈的直射光源，以免在标定板上产生眩光或阴影。


#### 外参（相机相对值）

这里标定的是多个相机之间的相对外参关系，而不是相机与机械臂等其他设备的外参关系。

```bash
airdc +demonstrator.instance.components.ignore_roles="[l,f]" samplers=video_once dataset.directory=scripts/calibration/camera/calibration/extrinsic
```

上述命令会同时启动多个相机，并同时采集所有相机的视频数据。多次重复录制会覆盖之前的数据。完成后，将会在`dataset.directory`指定的目录下找到每个相机的视频文件。

有如下录制建议：

- 确保覆盖范围与视场重叠：
  - 移动 Charuco 标定板时，应覆盖所有相机视场相互重叠的整个空间区域。
  - 确保不同相机之间有充足的视场重叠区域，这对多相机系统的标定至关重要。

- 使用方格尺寸足够大的标定板：
  - 较大的 ArUco 标记可以从更远距离被可靠识别，从而支持更大捕捉体积的标定。

- 尽量减少运动模糊：
  - 运动模糊会严重影响角点检测的准确性。
  - 使用更高的帧率有助于减轻运动模糊。
  - 但更高的帧率通常需要更强的照明，以维持良好的画面亮度。

- 保持对焦一致：
  - 如条件允许，请使用手动对焦，以在整个录制过程中保持焦点稳定。
  - 自动对焦可能在不同帧之间产生不一致，影响标定效果。

- 用标定板定义坐标系原点（便于后续处理）：
  - 此操作仅为方便，并非强制要求。
  - 将标定板垂直持握并使其底部接触地面。
  - 确保标定板左上角（如 Charuco 页面所示）处于相机视野内，并同时接触地面。
