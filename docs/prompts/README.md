# Prompts 框架说明

本目录下包含了各种 Prompt 模板，旨在帮助用户快速构建和定制化他们的数据采集链路。

## 目录结构

- `meta`：包含用于构建程序框架的元提示模板。普通用户不应使用这些模板，除非他们希望修改或扩展框架本身。
  - `doc_tpl.md`：用于生成文档的提示模板。
  - `test_tpl.md`：用于测试程序开发的提示模板。
  - `doc_and_test.md`：用于触发文档和测试生成的提示。
- `prepare`：最先声明的提示信息，用于行为约束，例如如何创建环境、遇到问题如何处理等。
- `compatibility`：在确保兼容的前提下进行外部程序向本框架的迁移的提示参考。
- `trigger`：一些其他常用的顶层的提示词示例。
